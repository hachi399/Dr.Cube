## 概要

SampleUIフォルダには、**UI/UXのみのデモバージョン**が含まれています。実際のシステム機能（API呼び出し、データベース操作）は削除され、**視覚的な動作とアニメーションのみ**が実装されています。

### 構成
- `index.html` - メイン画面（4画面を同時表示）
- `analysis.html` - AI解析チャット（iframe内で表示）
- `idea.html` - 連想マップ（iframe内で表示）
- `image.html` - 画像アップロード（iframe内で表示）

## index.html - メイン画面（4画面表示システム）

### 🎯 機能概要

PCで4つの画面を横並びに表示し、各画面で異なる機能を提供するマルチビューシステムです。

### 📐 画面構成

```
┌─────────┬─────────┬─────────┬─────────┐
│  画像   │  解析   │  発想   │  深掘り │
│ (image) │(analysis)│ (idea) │ (idea)  │
└─────────┴─────────┴─────────┴─────────┘
```

### 🔑 主要機能

#### 1. **4画面表示システム**
- **実装箇所**: `deck`配列（279-284行目）
- **仕組み**: 4つのカードオブジェクトを配列で管理
  ```javascript
  let deck = [
    { type: 'image', label: '画像', fixed: true },
    { type: 'analysis', label: '解析', fixed: true },
    { type: 'idea', label: '発想(1)', mode: 'new' },
    { type: 'idea', label: '深掘り(1)', mode: 'deep' }
  ];
  ```
- **表示制御**: `render()`関数（505-522行目）で`visible`クラスを切り替え

#### 2. **画面数切り替え（4→3→2→1画面）**
- **実装箇所**: `viewCountBtn`クリックイベント（576-580行目）
- **動作**: 画像から順に非表示
  - 4画面: 画像、解析、発想、深掘り
  - 3画面: 解析、発想、深掘り
  - 2画面: 発想、深掘り
  - 1画面: 深掘り
- **コード参照**: `getVisibleIndices()`関数（290-297行目）

#### 3. **スワイプジェスチャー**
- **実装箇所**: `swipe-layer`の`pointerdown/up`イベント（477-498行目）
- **動作**:
  - ロック中のみ有効（`overlayEnabled === true`）
  - 右スワイプ（`dist > 0`）で発想カードを新規作成
  - 40px以上の移動で発動
- **アニメーション**: フェードアウト（`opacity: 0`）→ 300ms後に削除・再作成
- **コード参照**: `handleSwipe()`関数（525-561行目）

#### 4. **ロック/操作可能トグル**
- **実装箇所**: `toggleIframeInteraction`ボタン（582-599行目）
- **視覚的表現**:
  - **ロック中**: 赤系（`#3a2a2a`背景、`#ff9999`文字）
  - **操作可能**: 緑系（`#2d4a2d`背景、`#99ff99`文字）
- **CSS疑似要素**: `::before`で「ロック中」「操作可能」を表示（193-209行目）
- **動作**: `overlayEnabled`フラグでスワイプレイヤーの`pointer-events`を制御

#### 5. **発想カードの「増やす」ボタン**
- **実装箇所**: `createCard()`内（334-372行目）
- **動作**: クリックで新しい発想カードを生成
- **アニメーション**: フェードアウト→削除→新規作成（363-370行目）

#### 6. **履歴ナビゲーション（←→ボタン）**
- **実装箇所**: ヘッダーとフッターの矢印ボタン（377-441行目）
- **機能**: 発想/深掘りの履歴を前後に移動
- **視覚的フィードバック**: 無効時は`opacity: 0.3`（86-89行目）

### 🎨 アニメーション詳細

#### カード表示/非表示
- **CSS**: `transition: opacity 0.3s ease`（41行目）
- **実装**: `visible`クラスの追加/削除で`display: flex`を切り替え（44-46行目）

#### ボタンホバーエフェクト
- **ナビゲーションボタン**: `transform: scale(1.1)`（83行目）
- **追加ボタン**: `transform: scale(1.05)`（104行目）
- **一般ボタン**: `transform: translateY(-1px)`（166行目）

#### トグルボタン
- **ホバー**: `transform: scale(1.02)`（213行目）
- **トランジション**: `transition: all 0.3s ease`（183行目）

### 📍 コード参照箇所

| 機能 | 行番号 | 説明 |
|------|--------|------|

## analysis.html - AI解析チャット画面

### 🎯 機能概要

AI解析結果をチャット形式で表示するインターフェース。モックデータで動作をデモンストレーションします。

### 🔑 主要機能

#### 1. **自動データ表示**
- **実装箇所**: `DOMContentLoaded`イベント（229-265行目）
- **動作**:
  1. 500ms後にモックデータを表示
  2. さらに1000ms後にAI解析結果を表示
- **アニメーション**: `fadeIn`アニメーション（62-65行目）

#### 2. **チャット送信機能**
- **実装箇所**: `sendMessage()`関数（270-302行目）
- **動作**:
  - 入力欄のテキストをチャットに追加
  - 500ms後にモック応答を表示
- **キーボードショートカット**: Enterキーで送信（304-308行目）

#### 3. **スクロール連動**
- **実装箇所**: `PASS_WHEEL`メッセージ受信（216-224行目）
- **仕組み**: 親ページ（index.html）のスクロールイベントをiframe内に転送
- **用途**: スワイプレイヤー上でスクロールしてもチャットがスクロール

### 🎨 アニメーション詳細

#### メッセージ表示
- **CSS**: `animation: fadeIn 0.3s ease`（60行目）
- **キーフレーム**: `from { opacity: 0; transform: translateY(10px); }`（63行目）

#### バッジ表示
- **データバッジ**: `slideIn`アニメーション（80-85行目）
  - 左からスライドイン（`translateX(-20px)`）
- **AIバッジ**: 同様の`slideIn`アニメーション（96行目）

#### コンテンツ表示
- **データコンテンツ**: `fadeIn 0.5s ease`（110行目）
- **AIコンテンツ**: 同様の`fadeIn 0.5s ease`（124行目）

#### ボタンホバー
- **送信ボタン**: `transform: translateY(-1px)`（175行目）
- **フォーカス**: 青いグローエフェクト（`box-shadow: 0 0 0 2px rgba(0, 102, 204, 0.2)`）（160行目）

### 📍 コード参照箇所

| 機能 | 行番号 | 説明 |
|------|--------|------|
| 自動データ表示 | 229-265 | `DOMContentLoaded`イベント |
| チャット送信 | 270-302 | `sendMessage()`関数 |
| スクロール連動 | 216-224 | `PASS_WHEEL`メッセージ受信 |
| アニメーション定義 | 62-65, 80-85 | CSS `@keyframes` |

### 🎨 カラースキーム

- **データバッジ**: 青系（`#0066cc`、`rgba(0, 102, 204, 0.1)`）
- **AIバッジ**: 緑系（`#00cc66`、`rgba(0, 204, 102, 0.1)`）
- **背景**: 黒（`#000000`）、チャットエリア（`#1a1a1a`）

## idea.html - 連想マップ（D3.js可視化）

### 🎯 機能概要

D3.jsを使用したインタラクティブな連想マップ。ノードとリンクで概念間の関係を可視化します。

### 🔑 主要機能

#### 1. **3段階階層構造**
- **構造**: 親（depth: 0）→ 子（depth: 1）×6 → 孫（depth: 2）×3×6
- **実装箇所**: `addSeedBtn`クリックイベント（441-486行目）
- **生成ロジック**: モックデータで順次生成（461-480行目）

#### 2. **物理シミュレーション（D3 Force）**
- **実装箇所**: `d3.forceSimulation()`（234-243行目）
- **力の設定**:
  - `forceLink`: ノード間の距離（親子: 45px、子孫: 60px）
  - `forceManyBody`: 反発力（`-80`）
  - `forceCenter`: 中心への引力
  - `forceCollide`: 衝突検出
- **更新**: `ticked()`関数で毎フレーム位置を更新（428-439行目）

#### 3. **ズーム・パン機能**
- **実装箇所**: D3.jsの`zoom`機能（174-186行目）
- **操作**:
  - マウスホイール: ズーム
  - ドラッグ: パン（移動）
- **制限**: ロック中は無効（`isLocked === true`）
- **ボタン**: `zoomInBtn`/`zoomOutBtn`（188-200行目）

#### 4. **ノードインタラクション**
- **ホバー**: ツールチップ表示（328-345行目）
- **クリック**: ロック解除時は詳細表示（318-326行目）
- **テキスト調整**: `fitTextToCircle()`で円内に収める（347-376行目）

#### 5. **リンクホバー**
- **実装箇所**: リンクの`mouseover`イベント（292-308行目）
- **表示**: 関連性の説明をツールチップで表示

#### 6. **ノードサイズ調整**
- **実装箇所**: `addNode()`関数（261-285行目）
- **計算**: テキスト長に応じて半径を調整（`Math.min(Math.max(18, textLength * 2.5), 30)`）

### 🎨 アニメーション詳細

#### ノード生成
- **順次生成**: `setTimeout`で150ms間隔（123-136行目）
- **視覚的効果**: D3の`forceSimulation`が自動でアニメーション

#### ツールチップ
- **CSS**: `animation: fadeIn 0.2s ease`（22行目）
- **キーフレーム**: `from { opacity: 0; transform: translateY(-5px); }`（23行目）

#### ノード詳細表示
- **CSS**: `animation: slideDown 0.3s ease`（31行目）
- **キーフレーム**: `from { opacity: 0; transform: translateY(-20px); }`（32行目）

#### コントロールパネル
- **ホバー**: `box-shadow`が拡大（`0 2px 8px` → `0 4px 12px`）（11行目）
- **トランジション**: `transition: all 0.3s ease`（10行目）

#### ボタンホバー
- **ズームボタン**: `transform: scale(1.1)`（18行目）
- **リセットボタン**: `transform: scale(1.05)`（20行目）
- **メインボタン**: `transform: translateY(-1px)`（14行目）

### 📍 コード参照箇所

| 機能 | 行番号 | 説明 |
|------|--------|------|
| ノード生成 | 261-285 | `addNode()`関数 |
| 物理シミュレーション | 234-243 | `d3.forceSimulation()` |
| ズーム機能 | 174-186 | D3.js `zoom` |
| ノード描画 | 287-426 | `restart()`関数 |
| 位置更新 | 428-439 | `ticked()`関数 |

### 🎨 ビジュアルデザイン

- **ノード**: 白背景（`#ffffff`）、青枠（`#0066cc`、2px）
- **リンク**: 黒線（`#000000`、1.5px、`opacity: 0.4`）
- **背景**: 白（`#ffffff`）
- **ツールチップ**: 白背景、青枠（ノード）または黒枠（リンク）

## image.html - 画像アップロード画面

### 🎯 機能概要

画像をアップロードし、プレビューと解析結果を表示するシンプルなインターフェース。

### 🔑 主要機能

#### 1. **ファイル選択**
- **実装箇所**: `handleFile()`関数（165-186行目）
- **動作**:
  - ファイル選択でプレビュー表示
  - ファイル名をラベルに表示（長い場合は省略）
- **視覚的フィードバック**: ラベルにファイル名を表示（177行目）

#### 2. **画像プレビュー**
- **実装箇所**: `FileReader`でBase64変換（181-185行目）
- **アニメーション**: `fadeIn`アニメーション（82-87行目）
  - スケールアニメーション（`scale(0.95)` → `scale(1)`）

#### 3. **解析処理（モック）**
- **実装箇所**: `processImage()`関数（188-224行目）
- **動作**:
  1. ローディング表示開始
  2. 2秒後にモック結果を表示
  3. ローディング終了
- **ローディング**: 3つのドットが順次アニメーション（122-136行目）

#### 4. **結果表示**
- **実装箇所**: `output`要素への表示（216-217行目）
- **アニメーション**: `slideIn`アニメーション（103-106行目）

### 🎨 アニメーション詳細

#### 画像プレビュー
- **CSS**: `animation: fadeIn 0.5s ease`（82行目）
- **キーフレーム**: 
  ```css
  from { opacity: 0; transform: scale(0.95); }
  to { opacity: 1; transform: scale(1); }
  ```

#### ローディングアニメーション
- **実装**: `bounce`アニメーション（133-136行目）
- **動作**: 3つのドットが順次拡大・縮小
- **タイミング**: 各ドットに異なる`animation-delay`（131-132行目）

#### 結果表示
- **CSS**: `animation: slideIn 0.4s ease`（101行目）
- **キーフレーム**: 
  ```css
  from { opacity: 0; transform: translateY(-10px); }
  to { opacity: 1; transform: translateY(0); }
  ```

#### ボタンホバー
- **ファイル選択ラベル**: `transform: scale(1.02)`（52行目）
- **解析ボタン**: `transform: translateY(-1px)`（68行目）
- **アクティブ**: `transform: translateY(0)`（71行目）

### 📍 コード参照箇所

| 機能 | 行番号 | 説明 |
|------|--------|------|
| ファイル選択 | 165-186 | `handleFile()`関数 |
| 画像プレビュー | 181-185 | `FileReader`処理 |
| 解析処理 | 188-224 | `processImage()`関数 |
| ローディング | 122-136 | CSS `@keyframes bounce` |

### 🎨 カラースキーム

- **背景**: 黒（`#000000`）
- **ボタン**: 青（`#0066cc`）、ホバー（`#0052a3`）
- **結果ボックス**: ダークグレー（`#1a1a1a`）、青い左ボーダー（`#0066cc`）

## 共通のアニメーション・UXパターン

### 🎨 共通アニメーション

#### 1. **フェードイン（fadeIn）**
```css
@keyframes fadeIn {
  from { opacity: 0; transform: translateY(10px); }
  to { opacity: 1; transform: translateY(0); }
}
```
- **使用箇所**: メッセージ、コンテンツ表示
- **意図**: スムーズな出現効果

#### 2. **スライドイン（slideIn）**
```css
@keyframes slideIn {
  from { opacity: 0; transform: translateX(-20px); }
  to { opacity: 1; transform: translateX(0); }
}
```
- **使用箇所**: バッジ、結果表示
- **意図**: 横方向からの出現で注意を引く

#### 3. **ボタンホバー**
- **パターン1**: `transform: translateY(-1px)` - 軽く浮き上がる
- **パターン2**: `transform: scale(1.1)` - 拡大
- **意図**: インタラクティブ要素であることを示す

#### 4. **トランジション**
- **標準**: `transition: all 0.2s ease`
- **長め**: `transition: all 0.3s ease`
- **意図**: 滑らかな状態変化

### 🎯 UXパターン

#### 1. **ローディング状態**
- **パターン**: ボタンテキスト変更 + ローディングアニメーション
- **例**: 「解析」→「解析中...」+ ドットアニメーション

#### 2. **無効状態**
- **パターン**: `opacity: 0.3` + `cursor: default`
- **例**: 履歴ナビゲーションボタン

#### 3. **フィードバック**
- **パターン**: 即座の視覚的変化（色、サイズ、位置）
- **例**: ボタンホバー、フォーカス状態

#### 4. **階層表示**
- **パターン**: バッジ + コンテンツボックス
- **例**: データバッジ + データコンテンツ

## 🔍 デバッグ・カスタマイズのヒント

### アニメーション速度の調整
- **CSS**: `transition`や`animation`の`duration`を変更
- **JavaScript**: `setTimeout`の遅延時間を調整

### カラースキームの変更
- 各ファイルのCSS変数または直接色指定を変更
- 主要カラー: `#0066cc`（青）、`#00cc66`（緑）、`#1a1a1a`（ダークグレー）

### レスポンシブ対応
- 現在はPC向け（4画面表示）
- モバイル対応には`@media`クエリを追加

## 📝 まとめ

SampleUIは、**視覚的な動作とアニメーションに焦点を当てたデモバージョン**です。実際のシステム機能は含まれていませんが、UI/UXの動作を確認・テストするのに最適です。

各UIは独立して動作しますが、`index.html`を通じて統合され、一貫したユーザー体験を提供します。
